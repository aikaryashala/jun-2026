### 1. `char` in C and Binary Representation

In C, `char` has `unsigned char` and `signed char` data types, both of which use 1 byte of memory.

For `unsigned char`, all the bits are used to represent the magnitude, so the range is `[0, 255]`.

For `signed char`, the range is `[-128, +127]`. Negative numbers are represented using **2's complement**, which is the **1's complement of the positive number + 1**.

Give examples showing how `-5`, `-15`, and `-128` are represented in memory, step by step.

Create a debugging task in C using:

```c
signed char num1 = -5;
signed char num2 = -15;
signed char num3 = -128;
```

Show how to inspect these values in the debugger.

Also explain the LLDB commands needed to inspect the memory byte in **binary format**.

---

Give **two examples for each operator**, showing the input values, operation, and result.

### 3. NAND Gate and NAND2Tetris

Also explain the purpose and learning approach of the course:

[https://nand2tetris.org](https://nand2tetris.org)

Connect the idea of NAND gates and binary representation to how computers are built from the lowest level upward.

### 4. Bitmap Representation and Image Masks

Suppose we want to change the background of an image where a person is present in the photo.

One way to represent the person's location is as a list of pixel positions in the image, such as `(i, j)` coordinates in a matrix. This can require a lot of memory.

The same information can be represented as a **bitmap/mask**, where:

* `0` represents background pixels.
* `1` represents pixels belonging to the person.

Explain how this representation saves memory.

Then explain how the mask can be applied to the original image to remove the background, how the **inverted mask** can be used to create the background, and how the foreground and background images can finally be combined to produce the final image.

---

### 5. N Bytes and Number Representation

We know that one byte can hold:

* Unsigned values from `0` to `(2^8) - 1`
* Signed values from `-(2^7)` to `+(2^7 - 1)`

Explain the general rule for **N bytes**.

For example, explain why a signed integer using `N` bytes can represent numbers from:

`-(2^(8N-1))` to `+(2^(8N-1) - 1)`

Also explain the corresponding unsigned range.

---

### 6. IPv4 Addressing

An IPv4 address contains **4 bytes**, where each byte can have a value from `[0, 255]`.

Therefore, the total number of possible IPv4 addresses is:

`256^4 = 2^32`

Explain this clearly.

Among these addresses, some ranges are used for private/local networks, some are publicly routable, and some are reserved for special purposes.

List the major categories of IPv4 addresses and their reserved ranges, including:

* Private addresses
* Loopback
* Link-local
* Multicast
* Broadcast
* Documentation/example ranges
* Other important reserved/special-purpose ranges

Explain why these ranges exist and where they are used.

---

* Address space
* Scalability
* Network configuration
* Routing
* Security-related capabilities
* IoT and future connectivity
* Other important capabilities enabled by IPv6
